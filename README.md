## Project Overview
This repository contains three introductory web development projects built with HTML and CSS. Each project presents information for a different topic and demonstrates webpage structure, styling, layout, and content organization.

### Project Files
- `gamezone.html` — Gaming and esports community webpage
- `healthfood&nutrition.html` — Healthy food and nutrition webpage
- `tourism&heritage.html` — Indian tourism, heritage, and culture webpage
- `1.css`, `2.css`, `3.css` — CSS stylesheets used by the webpages

---

## Case Study 1: GameZone — Gaming and Esports Community

### Objective
To create a webpage that presents gaming information, esports tournament schedules, player rankings, and community news in one place.

### Main Features
- Popular games such as BGMI, Valorant, and Free Fire
- Tournament schedule information
- A top players table showing rank, player name, and points
- A gaming news and community message
- Dark background, bright teal headings, and grouped content panels

### Web Development Concepts
- HTML headings and content sections
- Tables for displaying player rankings
- CSS colors, spacing, borders, and rounded panels
- Consistent visual styling for a gaming theme

### Outcome
This project demonstrates how HTML and CSS can present gaming-related information in a clear, organized, and visually consistent layout.

---

## Case Study 2: Explore India — Tourism, Heritage, and Culture

### Objective
To develop an informational webpage introducing Indian destinations, historical monuments, cultural festivals, cuisine, and travel tips.

### Main Features
- Famous destinations such as the Taj Mahal, Goa, and Kashmir
- Historical monuments such as the Taj Mahal, Red Fort, and Charminar
- Cultural festivals including Diwali, Holi, and Sankranti
- A local cuisine section
- Practical travel tips and an “Explore More” button

### Web Development Concepts
- Organizing information into separate sections
- Repeated content panels
- CSS background colors, typography, spacing, and alignment
- Buttons and page footers

### Outcome
This project shows how a travel and culture website can organize varied information into readable sections with a consistent design.

---

## Case Study 3: Healthy Food & Nutrition

### Objective
To create a webpage sharing basic healthy-eating ideas, recipe suggestions, nutrition information, and meal-planning guidance.

### Main Features
- Healthy recipe suggestions such as vegetable salad and fruit bowls
- A nutrition section with an example apple calorie fact
- Meal-planning guidance focused on fruits, vegetables, and whole grains
- Healthy eating tips, including drinking enough water and eating a balanced diet
- An “Explore Recipes” button

### Web Development Concepts
- Card-based layouts
- CSS alignment, spacing, backgrounds, and typography
- Grouping related information into visual cards
- Using colors that suit the topic

### Outcome
This project demonstrates how HTML and CSS can present health and nutrition information in a simple, accessible, and organized format.

## Overall Learning Outcomes
- Practiced structuring webpage content with HTML.
- Used CSS to style colors, typography, spacing, alignment, and panels.
- Presented information through sections, cards, tables, and buttons.
- Applied different visual themes to suit different project topics.
- Reviewed webpages in a browser to check their rendered appearance.

## Conclusion
These three projects—GameZone, Explore India, and Healthy Food & Nutrition—provide practical experience in basic front-end web development. They demonstrate how HTML structures content and CSS improves presentation, readability, and visual consistency.
